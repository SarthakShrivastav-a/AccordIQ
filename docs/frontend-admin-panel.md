# Frontend Admin Panel

The frontend is a Next.js SaaS admin console with a disciplined neo-brutalist
design system. It consumes real AccordIQ backend APIs only. Empty states are
truthful product states, not generated sample rows.

Current surfaces:

- Login and Google OAuth callback.
- SaaS onboarding and organization creation.
- Organization members and invites.
- Slack/Notion integration status.
- Usage metering.
- Capture policy.
- Workspace, review, jobs, audit, settings, and grounded query views.
